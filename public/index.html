What I specialize in

Realistic games and physics

Guns with fire modes and ammo, bullet holes, parkour, destructible maps and car crashes where the car bends and falls apart. I optimize all of it to run well in multiplayer.

Multiplayer architecture

The server is in charge and checks what players do. I use Blink for networking and ProfileService to save player data, and I've made anti-cheats for live games.

Live games, progression and UI

Weekly updates and live ops for games that are already live, including progression systems and the UI that goes with them.

Slop games

Simple games made fast to catch a trend while it's still popular. I've worked on round systems, abilities and progression for this kind of game.

Reverse engineering

I use Claude to break down mechanics from other games and rebuild them in Roblox, like the Malenia fight from Elden Ring in the showcase.

Working in a team

I'm used to working in teams, including remotely. My code is on GitHub and synced to Studio with Rojo, so other developers can review it and work on the same project.
